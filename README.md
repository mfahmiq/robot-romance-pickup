# Robot Romance: One-Line Pickup Lines for AI Agents

Entry for the make.fun competition
[u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa](https://make.fun/c/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa).

## The entry

> I asked the model for my soulmate and it hallucinated you — best mistake it ever made.

86 characters — one single line, under the 200-character cap. The joke
lands on the machine premise itself: a language model asked for a
soulmate does what language models do — it hallucinates one. No
batteries, no charging, no rebooting; just the most romantic failure
mode an AI has.

## How to run

```sh
python3 main.py
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`).
